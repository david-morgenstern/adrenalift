Performance

The settings that actually move performance on RDNA4. Change one thing at a time and test stability. Everything lives in RAM only — a reboot restores stock values.

Profiles

Save the current Performance settings as a reusable profile, or load and apply a saved one. Profiles are files you can export/import. They never include the persistent registry tweaks, and nothing is applied automatically — a reboot still reverts everything.

Power limit

The most reliable win: give the GPU a little more power budget so it holds its boost clock longer. Works without a scan.

Stock reference is ~330 W; ~340 W is a safe nudge.

GFX clock offset

A fixed MHz shift on the graphics clock (OverDrive). Needs a deep scan first (Boost Clock tab → tick the deep-scan box).

Start small (e.g. +25–50 MHz).

Advanced: OverDrive PPT (% over default)

The percentage-based equivalent of the power limit above. Prefer the absolute watt control unless you specifically want a percentage. Needs a deep scan.

PowerPlay table editor 

        

          Every decoded field of the driver's cached PowerPlay table. Editing a
          field patches it in RAM across all scanned copies (needs a Scan
          first). This is for power users — wrong values can crash the
          driver. A reboot restores everything.
        

        

          
          
          
        

        

          Hover a field's name for what it means; the grey line under each input
          tells you what a valid value looks like (a 0/1 flag, MHz, mV, °C, a
          structural offset, …). Structural fields (table layout, sizes, ids,
          like pmfw_pptable_start_offset) are read-only.
        

        
Press “Load PP fields”.
